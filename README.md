# Aegirine

An experimental PS1 emulator for Android, built on the frontend of
[Ametrine](https://github.com/kiraponz/Ametrine) (library, settings, touch controls,
controllers). The emulation core is not wired in yet.

> Aegirine is an unofficial project. It is not affiliated with Sony Interactive Entertainment.
